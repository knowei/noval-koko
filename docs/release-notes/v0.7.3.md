## 章节图是怎么解的

这一站的章节页里没有 `<img>`，只有一串 `var params = '...'`（六万多字符的密文）。
做法不是自己重写 AES，而是**把站点自己的 `crypto-js` 和 `cms-2.0.1.min.js` 直接 `eval` 进 QuickJS**，
挂一个钩子把 `CryptoJS.AES.decrypt` 的明文抓出来（hex → UTF-8 → JSON），
拿到 `chapter_images` 与 `images_domain` 再拼成绝对地址。

好处是站点以后换密钥、换填充方式都不用改规则；代价是每个章节页要多跑一次解密脚本（已做库缓存，只跑一次）。

## 顺手修的两个写源语义坑

- **`@css:a@text` 在「当前节点本身就是 `<a>`」时取不到值**：`querySelectorAll` 只找后代，
  而且 `@` 会被规则拆分器拆成空段。章节名/链接要写成单段 `"text"` / `"href"`。
- **`tocUrl` 别写 `@js:baseUrl`**：会算出一个错值，表现是「目录为空」；留空让引擎回落 bookUrl 即可。
