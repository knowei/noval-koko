## 墨町 0.7.0

### 新功能
- **换源**：详情页新增「换源」按钮，会拿书名去所有已装书源里搜一遍，边搜边出候选；切过去后章节列表和阅读进度自动迁移，旧条目自动删掉
- **章节搜索**：目录页右上角新增搜索按钮，长篇小说不用再一路滑——输章节名模糊匹配，或者直接输数字跳到第 N 章（比如输 1600 直接到第 1600 章）
- **新书源：MangaBZ**（mangabz.com），漫画源，搜索/目录/整章图片全部跑通

### 修复
- 封面和漫画图片不显示：图片请求现在按书源携带 Referer（有些图床必须带站内 Referer 才给图，有些反而带 Referer 就 403，现在按源分别处理）
- 搜索结果按源轮流交错展示，不再让某一源的结果把整屏刷满

### 规则引擎
- `searchUrl` 里的 JS 现在能拿到 `key` / `page`，兼容 Legado 里 `@js:'...'+encodeURIComponent(key)` 这类写法
- JS 上下文补充 `book.bookUrl` / `chapter.url`，兼容以 `book.` / `chapter.` 取值的第三方规则
- 新增「整段 packed JS 解包器」，处理漫画站用 `eval(function(p,a,c,k,e,d))` 混淆图片地址的情况
- 书源可选 `checkKeyWord` 不参与相关性过滤，避免繁体站被简体关键词误杀

### 其他
- 网络诊断页（书源详情 / 我的页）：按域名逐个探 DNS、TCP、HTTP，源失效时先看清是网络问题还是规则问题
- 书源过 Cloudflare 人机验证：书源菜单会给出具体步骤，过完的 Cookie 从「我的 → 粘贴 Cookie」导入，本地持久化复用，直到过期
