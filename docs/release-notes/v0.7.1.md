## 修复

- **漫画图片可能加载不出来**：正文整理时漏传了图片请求要用的 `Referer`，
  mangabz 这类图床会直接 403。现在该字段原样透传，并加了单测守着。
- **书源体检不再说谎**：以前「搜索请求没报错」就当可用，搜出 0 条也算，
  结果出现「搜得到、点进去正文是空的」。现在按链路分五级：
  网络失败 / 搜索无结果 / 仅搜索通过 / 详情·目录·正文失败 / 可读。
- **批量体检不再压测站点**：批量只跑搜索、逐源间隔 250ms；
  要验正文请用书源行里的「深度体检（读一章）」。
- **清理误导入口**：「我的」页原来的「浏览器过验证」已无内置浏览器，
  两个卡片合并为「过人机验证 / 粘贴 Cookie」；书源行里的同名入口文案同步改准。

## 安全

- 发版工作流支持从 Secrets 注入签名（`ANDROID_KEYSTORE_B64` 等四个），
  没配时回退到仓库内的 keystore，构建不受影响。
  README 写明迁移顺序：**先配 Secrets 跑通一次发布，再把私钥文件移出仓库**。
