## 墨町 0.6.0

### 新功能
- **暗色模式**：外观设置里新增「跟随系统 / 浅色 / 深色」，选跟随系统时随手机/电脑的外观自动切换，选择会被记住
- **更新说明**：应用内检查更新的弹窗现在会显示这个版本改了什么，不再是一串 compare 链接

### 界面
- 界面字体改用系统中文字体（Windows 微软雅黑 / Android Noto Sans CJK / iOS 苹方），修掉中文被回退到衬线字体导致的小字号发虚、笔画粗细不齐
- 字重统一为「常规 / 加粗」两档，避免中文合成加粗把笔画糊在一起

### 阅读器
- 正文字体可选：宋体（默认）/ 黑体 / 楷体 / 系统默认
- 行距默认放宽到 1.85，长段落读起来不那么挤

### 修复
- 阅读进度：读到很后面退出阅读器再进来，会回到旧章节的问题（内存里的书架对象没跟着更新）
- 详情页操作按钮在手机尺寸下被挤成两行
