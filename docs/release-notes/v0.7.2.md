## 安全

签名私钥彻底移出仓库：`android/app/noval-release.jks` 和 `android/key.properties`
已从版本库移除并写进 `.gitignore`，CI 打包时从 Secrets
（`ANDROID_KEYSTORE_B64` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` /
`ANDROID_KEY_PASSWORD`）还原 keystore。

签名证书没有变，还是同一把钥匙（SHA-256 `65:8F:13:44:…:DC:E1`），
所以手机上的 0.7.1 可以直接覆盖升级，不需要卸载。

工作流同时改严了：缺少签名 Secrets 会直接 **失败**，不再静默回退到 debug key ——
那种包签名对不上，装上去会变成"另一个应用"。

## 说明

- 本地打包照旧：把 jks 与 `key.properties` 放回 `android/` 下即可，只是别提交
- 这个版本功能与 0.7.1 一致，主要用于验证「Secrets 注入签名」这条发布链路
