# Noval UI 规范（照 dm / 木漏 的风格）

> 效果图见同目录 `01-shelf.png` ~ `06-sources.png`（AI 出的视觉稿，用作配色与版式基准，不是像素级终稿）。

## 0. 基调

一句话：**晨光纸质**。米白纸上排书，墨绿做唯一强调色，除封面之外几乎没有颜色；
信息靠字号/字重/间距分层，不靠卡片边框和阴影。中文标题粗黑，正文衬线，留白足。

三个「不要」：不要渐变按钮、不要彩色分区、不要给每个元素都加圆角阴影。

## 1. Design Tokens

新建 `lib/src/ui/theme/tokens.dart`，后面所有颜色/圆角/间距都从这里取。

### 颜色（Light）

| token | 值 | 用途 |
|---|---|---|
| `bg` | `#F7F9F3` | 页面底（米白偏绿） |
| `surface` | `#FCFDF8` | 卡片/浮层 |
| `surfaceAlt` | `#EFF3EA` | 搜索框、chip 底、头像底 |
| `primary` | `#5C7A68` | 主色（按钮、选中态、进度） |
| `primaryDeep` | `#4B7358` | 主色按压缩放 / 强调数字 |
| `ink` | `#2A3327` | 主文字（深墨绿，不是纯黑） |
| `inkMid` | `#6E7A6C` | 次文字（作者、域名、时间） |
| `inkFaint` | `#9AA396` | 占位符、禁用 |
| `line` | `#0000000F`（6% 黑） | 1px 分隔线 / 描边 |
| `ok` | `#4E9A6B` | 源可用点 |
| `bad` | `#C1564E` | 源失效点 |
| `idle` | `#9AA396` | 源未测点 |

### 颜色（Dark，仅阅读器 + 漫画用）

`bg #0F1613` / `surface #151E1A` / `primary #6E8F79` / `ink #EDEFE9` / `inkMid #9AA396` / `line #FFFFFF14`

### 间距与形状

- 栅格：8pt。页面左右 margin `20`。
- 圆角：`r8`(封面小图/头像) `r12`(封面) `r16`(卡片/输入框) `r999`(胶囊)
- 阴影：仅「继续阅读」卡片和浮层用 `0 2 12 rgba(20,30,20,0.06)`

### 字阶

| 名称 | 字号/行高 | 字重 | 用在哪 |
|---|---|---|---|
| display | 30 / 1.2 | w700 | 页面大标题（书架/搜索/书源） |
| title | 20 / 1.3 | w700 | 详情页书名 |
| section | 15 / 1.4 | w600 | 区块标题 |
| body | 15 / 1.6 | w400 | 列表书名 |
| meta | 12 / 1.4 | w400 | 作者、第 N 章、域名 |
| tag | 11 / 1.2 | w500 | 源名 chip、状态点标签 |

字体：中文用系统字体（Windows 微软雅黑 / Android 思源黑体）；
**阅读器正文例外**：`fontFamily: 'Noto Serif SC'`（缺字体时 fallback 到系统 serif），正文 18sp / 行高 1.85 / 首行缩进 2 字。

## 2. 组件

| 组件 | 规格 |
|---|---|
| `BookCover` | 3:4，r12，`BoxFit.cover`；无封面时用 `surfaceAlt` 底 + 书名首字居中（`inkFaint`） |
| `ProgressBadge` | 封面右上角，`rgba(0,0,0,.55)` + 白字 10sp，r8，padding 4/2 |
| `SourceTag` | 11sp `primary` 字 + `primary.withOpacity(.10)` 底，r999，padding 6/2（搜索结果里「后面跟源名」用它） |
| `FilterChip` | 选中：`primary` 填充 + 白字；未选中：透明 + `line` 描边 + `inkMid` 字。高 32，r999 |
| `SectionHeader` | 15sp w600 标题 + 右侧 12sp `inkFaint` 可点（「全部 ›」） |
| `SourceRow` | 40×40 首字母头像 + 名称(15/w600) + 域名(12/meta) + 状态点(8px) + `Switch`（`primary`，缩到 40×24） |
| `NavBar` | 自绘（不用 `NavigationBar`）：3 项，选中项图标+文字塞进 `primary` 胶囊（白字），未选中 `inkMid` 线性图标 |
| `ReaderSheet` | 阅读器底部设置面板：r16 顶部、`surface`、三行控件（字号滑块/行距三段/翻页三图标）+ 5 个主题圆点 |

## 3. 逐屏规格

### 3.1 书架 `01-shelf.png`
- 大标题 `书架` + 叶子 glyph；右上搜索图标；副行 `12 本 · 3 本追更中`（12sp meta）。
- 「继续阅读」横卡：左 3:4 封面 72×96，右书名/`第 N 章 · 3 天前`/进度条 42%/右下 `继续阅读` 胶囊按钮。
- 筛选 chip：全部 / 小说 / 漫画 / 追更。
- 网格：3 列，封面 3:4，下面两行（书名 w600 最多 2 行；`源名 · 第N章`）。
- 空态：居中 `surfaceAlt` 圆形插图位 + 「书架还空着」+ 两按钮「去搜索」「导入书源」。

### 3.2 搜索 `02-search.png`（**按用户要求：平铺，不聚合**）
- 大标题 `搜索`；搜索框 r16 `surfaceAlt`，左放大镜右清除。
- 结果头：`搜索结果 · 54 条` + 右侧 `全部书源 ▾` 下拉（按源筛选）。
- **列表直排**：每行 = 封面 56×74 + 书名(15/w600，2 行) + `作者` + `SourceTag(源名)` + 右 chevron。
  同一本书来自多个源 = 多行，靠 SourceTag 区分（这是用户明确要的，不做「聚合 + 换源」）。
- 交互：回车搜索、逐源流式返回（哪个源先回就先插哪行）、顶部显示 `已搜 3/12 源` 进度。
- 空态/错误：`没有找到「xx」` + 「换源再试」；单源失败不打断整体，只在结果头显示 `2 个源失败 ▾`（点开看原因）。

### 3.3 详情 `03-detail.png`
- 封面高斯模糊铺顶 + 渐隐到 `bg`；左上返回、右上分享（后续可做）。
- 前景封面 2:3（约 120×180）压住模糊块；书名 title；`作者 · 状态 · 类型` meta；两枚描边 chip：`源名`、`已加入书架 ✓`。
- 双按钮：`继续阅读 · 第 12 章`（primary 填充）+ `换源`（描边）。
- Tab：简介 / 目录（选中：w700 + 3px primary 下划线）。
- 目录行：`第 N 章` + 章名 + 未读橙点 + 已读态 primary 字 + 右侧更新时间；底部吸底条 `共 1076 章` / `倒序`。

### 3.4 文字阅读器 `04-reader-text.png`
- 无 AppBar；顶部 11sp 极细信息行：左章节名、右百分比。
- 正文：`#F5EFE2` 纸黄底、18sp、行高 1.85、首行缩进 2 字、左右 margin 24。
- 底部 12sp 行：左时间、右 `本章完 · 下一章 ›`。
- 点屏幕中间唤出 `ReaderSheet`（目录 / 设置 / 字号 / 行距 / 翻页模式 / 5 主题：纸黄 月白 豆绿 杏色 夜幕）。
- 保留现有能力：分页缓存（`_paginate`）、进度保存、空章提示、音量键翻页（后续）。

### 3.5 漫画阅读器 `05-reader-comic.png`
- 深色 `bg #0F1613`；顶部半透明条：返回 / `第 236 话 · 魔王的邀请` / 书签。
- 纵向长图整宽滚动，图间 8px 间隙；底部渐隐黑。
- 右下角竖进度轨（primary 手柄）；底部中央 `第 3 / 28 页` 胶囊。
- 单击唤出底栏：`上一话 / 目录 / 下一话` + 左侧竖向亮度条。
- 加载：图片位置用 `surface` 骨架 + 圆形进度；失败：`图片加载失败` + 重试。

### 3.6 书源管理 `06-sources.png`
- 大标题 `书源`；右上 `＋`（导入：粘贴/文件/剪贴板）与滑块图标（批量启用/停用/删除）。
- 汇总卡：`已导入 30 个书源` + `18 可用 · 9 失效 · 3 未测` + 分段进度条 + `重新检测`。
- 搜索框（源名/域名）+ 筛选 chip：全部 / 可用 / 失效 / 未测。
- 列表行：首字母头像 + 源名 + 域名 + 状态点 + 开关。
- 体检进度：卡片进度条实时走 + `18/30`，完成后可点「查看失败原因」进详情弹窗。

## 4. 落地顺序（建议）

1. `theme/tokens.dart` + 重写 `buildTheme`：seed 换成 `#5C7A68`，scaffold `#F7F9F3`，去掉紫色 `0xFF6C5CE7`；定义 `NavBar` 自绘组件。
2. `widgets.dart` 升级：`BookCover`（3:4 + 占位 + `ProgressBadge`）、`SourceTag`、`FilterChip`、`SectionHeader`。
3. 书架页：继续阅读卡 + 网格 + 筛选 + 空态。
4. 搜索页：改平铺（去掉聚合分组），每行挂 `SourceTag`，加「已搜 N/M 源」进度。
5. 详情页：模糊头图 + 双按钮 + 目录 Tab 样式。
6. 阅读器：`ReaderSheet`（字号/行距/翻页/主题）接到现有 `ReadPalette`；纸黄渐变底。
7. 书源页：汇总卡 + 状态点 + 体检进度。
8. 全局：`PageTransitionsTheme` 统一 iOS 式滑入，`AnimatedSwitcher` 150ms，触觉反馈仅长按。
